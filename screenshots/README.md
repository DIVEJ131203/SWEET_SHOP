# Screenshots Directory

This directory contains UI screenshots of the Sweet Shop application.

## Required Screenshots

To complete the README, please add the following screenshots:

1. **homepage.png** - Main dashboard showing product catalog with search and filters
2. **cart.png** - Shopping cart sidebar with items and checkout process
3. **admin-dashboard.png** - Admin panel showing analytics, product management, and order management
4. **mobile-view.png** - Mobile responsive design showing the app on mobile devices
5. **order-management.png** - Order tracking and management interface

## How to Add Screenshots

1. Take screenshots of your running application
2. Save them in this directory with the exact filenames mentioned above
3. The README.md will automatically display them

## Screenshot Guidelines

- Use high-quality PNG format
- Capture full browser window or mobile screen
- Show actual data (not empty states)
- Include both user and admin perspectives
- Demonstrate key features like search, cart, orders, etc.
